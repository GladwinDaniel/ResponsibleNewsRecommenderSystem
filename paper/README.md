# RespNews IEEE Paper

`respnews_ieee.tex` is an Overleaf-ready IEEE conference manuscript based on the supplied `IEEE Conference Template (1)` source.

## Overleaf upload

1. Create a blank Overleaf project.
2. Upload `respnews_ieee.tex`.
3. Upload `IEEEtran.cls` from `C:\Users\gladw\Downloads\IEEE Conference Template (1)` if Overleaf does not already resolve it.
4. Set the compiler to `pdfLaTeX` and set `respnews_ieee.tex` as the main file.
5. Compile twice so citations settle. If Overleaf still shows `??`, use Recompile from scratch to clear stale auxiliary files.

The paper deliberately reports the values from `checkpoints/experiment_results.csv` and identifies them as synthetic-mode results. Replace those values and the evaluation description only after a full real-data run is complete.
