# Figures

This directory contains all figures and diagrams used in the RespNews project.

## Contents
- Architecture diagrams (see `paper/respnews_ieee_recommenderSystem.tex` for TikZ source)
- Dashboard screenshots
- Benchmark comparison charts
- Pareto frontier plots
- Persuasion radar visualizations

## Note
The primary architectural diagrams are defined as TikZ/PGFPlots code in the LaTeX paper source.
Dashboard screenshots can be generated by running the frontend application.
