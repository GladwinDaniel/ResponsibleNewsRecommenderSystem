# Tables

This directory contains all CSV, XLSX, and JSON data files used in the RespNews project.

## Contents
- `experiment_results.csv` - Main benchmark comparison results
- `experiment_results.json` - Results in JSON format
- `experiment_results_run.csv` - Per-run experiment data
- `pareto_frontier.csv` - Pareto trade-off curve data (nDCG@10 vs PER)
- `train_users.json` / `dev_users.json` - User profile data
- `train_persuasion_profiles.json` / `dev_persuasion_profiles.json` - User susceptibility profiles
