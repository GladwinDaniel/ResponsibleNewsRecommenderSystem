# RespNews IEEE Paper

`respnews_ieee.tex` is an Overleaf-ready IEEE conference manuscript based on the supplied `IEEE Conference Template (1)` source.

## Overleaf upload

1. Create a blank Overleaf project.
2. Upload `respnews_ieee.tex`.
3. Upload the `figures/` folder containing the 3 vector PDF / PNG figures (`system_architecture.pdf`, `pareto_frontier.pdf`, `multimodal_comparison.pdf`).
4. Upload `IEEEtran.cls` from `C:\Users\gladw\Downloads\IEEE Conference Template (1)` if Overleaf does not already resolve it.
5. Set the compiler to `pdfLaTeX` and set `respnews_ieee.tex` as the main file.
6. Compile twice so citations settle.

The paper includes:
- 3 Author blocks: Gladwin Daniel P, Karthikeyan, and Dr. Vigneshwari S.
- 40 authoritative IEEE/ACM/ACL references covering news recommendation, GNNs, persuasion detection, multimodal encoders, and responsible AI.
- 3 high-resolution vector figures (System Architecture, Multimodal Comparison, and Pareto Frontier).
